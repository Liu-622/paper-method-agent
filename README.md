# 论文方法梳理智能体 · 小咕科研助手

面向时间序列预测领域，支持批量文献解析、方法自动分类、技术演进梳理与研究方向推导的科研辅助工具。

粤港澳大湾区 AI Coding 创新大赛参赛作品，赛题：AI + 学术科研助手 / 论文方法梳理智能体。

## 核心能力

- 批量文献解析：建立集合，多 PDF 导入，正文读取、模型分析、状态追踪、失败重试、内容去重与缓存。
- 方法自动分类：按模型家族、技术机制、研究任务组织方法，保留来源与证据，区分本文采用、相关工作、基线及未来工作。
- 技术演进梳理：方法地图、时间线、方法档案与关系证据。时间先后不自动构成继承关系。
- 研究方向推导：基于作者未来工作、局限及集合分析形成候选方向，传递问题、假设和实验条件至实施计划。

集合分析不限于三篇；2–3 篇限制仅用于深度比较。辅助功能包括论文问答、官方仓库线索检索、复现检查与小咕实验室。

## 本地启动

建议使用 Node.js 22 最新维护版本与 npm。本源码包不附带 Node 环境或 node_modules。

```powershell
npm ci
Copy-Item .env.local.example .env.local
# 在本机编辑 .env.local，填写自己的模型 Key。不要提交该文件。
npm run build
npm run serve
```

打开 http://127.0.0.1:8787/ 。后端自动读取本地环境配置；Ctrl+C 停止。

DeepSeek 配置模板采用 openai 兼容协议，这不表示使用 OpenAI 模型。本项目客户端会追加 `/v1/chat/completions`，因此 BASE_URL 不重复填写 `/v1`。

没有 Key 时，模型抽取、方法语义分析、模型问答等功能不可用；已提供的本地演示和实验室可运行部分仍可体验，不会假装已调用模型。

健康检查为 http://127.0.0.1:8787/api/health 。配置存在不等于调用成功，可运行 `node scripts/probe-minimal-llm.mjs` 做真实调用检查（需有效密钥，会消耗 API 额度）。

## 技术方案

React + TypeScript + Vite 前端；Node.js 服务端；PDF.js 正文读取；模型进行上下文语义分析，程序处理来源定位、规则校验和状态管理。论文与分析结果在用户浏览器持久化，密钥仅在服务端配置。

主要目录：

| 目录 | 内容 |
|---|---|
| src/ | 页面、交互、集合状态、分类、地图、方向与计划逻辑 |
| server/ | 模型接入、方法分析、方向、引用核对、侦探与实验 API |
| scripts/ | 构建、运行、回归检查及训练相关工具 |
| public/ | 内置公开文献正文缓存；PDF.js 字体在构建时生成 |
| data/ | ETTm2 公开实验数据及来源说明 |
| lab-models/ | 实验室权重、配置、归一化参数 |
| lab-cases/ | 内置实测案例记录，区别于用户运行记录 |
| third_party/ | 固定版本官方实现、原许可证及兼容补丁 |
| docs/ | 设计、部署及功能说明，部分文件记录历史版本 |

## 实验室边界

包含教学方法与官方 DLinear / Linear 方法，两类隔离展示。内置权重及实验只覆盖指定数据、跨度和配置，不能代表所有论文方法的复现或普遍优劣。不同时间片上的领先变化属于当前配置下的观察，不构成统计显著性或普遍规律。

Python 训练脚本见 `scripts/paper-method/`，重新训练需额外安装其 Python/PyTorch 等依赖；日常网页运行与已提供权重的 Node 推理不要求 Python。

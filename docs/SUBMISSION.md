## 2. 本地完整运行（这是能完整演示全部能力的运行方式）

```bash
# 1. 安装依赖
npm install

# 2. 配置模型（二选一）
#    Linux / macOS
export LLM_BASE_URL="https://api.deepseek.com/anthropic"
export LLM_API_KEY="sk-你的密钥"
#    Windows PowerShell
$env:LLM_BASE_URL="https://api.deepseek.com/anthropic"; $env:LLM_API_KEY="sk-你的密钥"

# 3. 构建前端（会自动把 pdfjs 的 cmaps 与标准字体复制进产物）
npm run build

# 4. 启动（前端 + 后端同一个端口）
node server/index.mjs
#    默认 http://127.0.0.1:8787/
```

验证后端与密钥是否就绪：

```bash
curl http://127.0.0.1:8787/api/health
# 期望：{"ok":true,...,"hasCredentials":true,"capabilities":{"realLlmExtract":true,"realLlmQa":true}}
```

常用自测命令：

| 命令 | 作用 | 是否调用模型 |
| --- | --- | --- |
| `npm run typecheck` | TypeScript 类型检查 | 否 |
| `npm run build` | 构建前端产物（含 pdfjs 资源） | 否 |
| `npm run test:verify` | 引用校验与集合型字段核验单测（13 项） | 否 |
| `npm run test:logic` | 检查逻辑回归测试（64 项：数据集身份、口径比较、未检查、三来源结论分类等） | 否 |
| `npm run test:e2e` | 端到端：真 PDF → 字段抽取 → 引用校验 → 带引用校验的问答 | 是（约 3 分钟） |

测试实际输出保存在 `docs/results/`（每次都重新运行，不沿用历史结果）。

## 3. 静态线上版 vs 完整后端版

| 能力 | 静态线上版 | 完整后端版（本地/自有后端） |
| --- | --- | --- |
| 页面、示例项目、检查规则、实验记录 | ✅ | ✅ |
| 真实 PDF 按页读取正文（浏览器端） | ✅ | ✅ |
| 原文件本地保存 / 刷新后免重选文件 | ✅ | ✅ |
| 字段抽取（模型） | ❌ 需要后端 | ✅ |
| 引用逐字校验、原文支持判定 | ❌ | ✅ |
| 模型问答（带引用校验、结论撤回） | ❌ 需要后端 | ✅ |
| 数据存放位置 | 全部在你的浏览器本地 | 全部在你的浏览器本地 |

页面在未连接后端时会**明确显示「未连接模型」**，并且不会用固定答案冒充模型回答。

把线上版接上后端只有一个动作：部署后端（`docs/BACKEND_NEEDED.md` 给了三种方式的完整命令），
然后用 `VITE_API_BASE=<你的后端地址> npm run build` 重新构建并部署静态站点，
此后评委打开公开链接即可直接使用全部功能，**不需要填写任何配置**。

## 4. 建议的演示流程（3 分钟视频的录制顺序）

完整命令与预期结果见 `docs/ACCEPTANCE.md`，这里是与视频节奏对应的顺序：

1. **0:00–0:20 开场**：打开首页，一句话说明定位 —— 「复现之前，先把论文里没写清楚的地方找出来」。
2. **0:20–0:50 真实上传**：论文库 → 上传两篇真实论文（DLinear、Autoformer）→ 展示按页读取进度与
   「已抽取 20 个字段 · 正文已本地保存 · 原文件已本地保存」。
3. **0:50–1:20 引用可核对**：打开任一字段的「查看依据」，对照 PDF 页码与英文原句（核心卖点 1）。
4. **1:20–1:55 共同数据集口径**：实验检查页 → 选共同数据集 ETTh1 → 展示判定随口径变化
   （ETTh1 上划分不同 = 存在差异；Traffic 上一致 = 条件一致），并说明「集合不同 ≠ 不可比较」。
5. **1:55–2:25 未找到 vs 未检查**：复现缺项页展示「未找到」与「未检查」的区别与页码，
   再用「修正这一项」演示人工补充（标注为人工补充，不覆盖论文原值）。
6. **2:25–2:45 结论三来源**：论文问答 → 展示「原文支持 / 部分支持 / 系统事实 / 规则推导」
   四类标签，以及「已撤回的结论（原文不支持）」区块。
7. **2:45–3:00 收尾**：说明当前边界（线上静态版缺后端、扫描件需 OCR）与下一步（部署后端后线上全功能）。

## 5. 已知限制（如实说明）

- **公开的静态地址没有后端**，模型两步在线上不可用（见第 3 节与 `docs/BACKEND_NEEDED.md`）。
- **扫描件不支持**：只处理文本型 PDF；图片版会提示需要先 OCR（未接入 OCR）。
- **长论文会截断**：送入模型的正文有上限（默认 90,000 字符），被丢弃的页码会在界面列出，
  并且相关字段会标成**「未检查」而不是「未找到」**。
- **抽取会漏抽**：论文其实写了但被判成「未找到」。这是刻意选择的失败方向（宁可说未找到也不编造），
  界面提供人工补充入口。
- **模型判定依赖模型**：引用支持判定与结论复核都由同一个模型完成，会偶发失败；
  失败时界面会明确标注「未复核」，不会假装通过。
- **不做的事**：方法排名、自动跑实验、自动写论文、登录/收费/权限、导出报告。

# 验收清单（照着走一遍，即可覆盖全部卖点）
# ------------------------------------------------------------------
# 说明：凡是「界面说了什么」都以界面为准；下面括号里是**预期结果**，如果和预期不符就是 bug。
# 建议同时开着 B 站/本地的两篇真实论文 PDF，方便核对引用。

## 0. 准备

```bash
npm install && npm run build
# Linux/macOS
export LLM_BASE_URL="https://api.deepseek.com/anthropic"
export LLM_API_KEY="sk-xxxx"
# Windows PowerShell
# $env:LLM_BASE_URL="https://api.deepseek.com/anthropic"; $env:LLM_API_KEY="sk-xxxx"
node server/index.mjs
```
打开 http://127.0.0.1:8787/ （前后端同源，无需额外配置）。
左下角「运行设置」应显示 **后端已连接**。

## 1. 真实上传与解析

1. 论文库 → 「我的论文库」→ 选择两篇**文本型** PDF。
   - 推荐：arXiv 2205.13504（DLinear）、arXiv 2106.13008（Autoformer）。
2. 观察状态流转：`排队中 → 读取 PDF 正文（第 n/m 页）→ 抽取字段中 → 字段已抽取`。
   （**预期**：进度条与控制台都有真实页码；每篇耗时约 30～100 秒。）
3. 列表出现：页数、字符数、「已抽取 20 个字段 · 正文已本地保存 · 原文件已本地保存」。

## 2. 引用可核对（核心卖点 1）

1. 点开任一篇的**论文详情** → 任意字段点「🔍 查看依据」。
   （**预期**：侧栏给出 论文名 + 第 N 页 + 英文原文片段 + 绿色「PDF 原文」标签。）
2. 把片段粘到 PDF 搜索框，能定位到同一页。
   （**预期**：一致。若模型给的引用对不上，该字段会被降级为「未找到」而不是硬说找到。）

## 3. 实验条件对比（核心卖点 2）

1. 勾选两篇 → 「方法对比」。
   （**预期**：并排展示数据集 / 划分 / 测试区间 / 跨度 / 采样间隔 / 指标 / 预处理 / 训练细节。）
2. 进「实验检查 → 实验公平性」，先看顶部的**对比口径**卡片。
   - 下拉里应列出**共同数据集**，并显示「x/y 篇包含」（例如 `ETTh1（2/3 篇包含）`）。
   - 选一个只被部分论文用到的数据集 → 顶部出现提示，说明缺该数据集的论文会被标「信息不足」。
   （**预期**：不会因为数据集集合不同就判「共同实验不可比较」；理由里会写出共同数据集与限定口径。）
3. 选共同数据集 `ETTh1` → 看「训练/测试划分」。
   （**预期**：DLinear 7:1:2 与 Autoformer 6:2:2 → **存在差异**（同一步数据集上条件不同）。）
4. 改选 `Traffic` → 再看同一项。
   （**预期**：两篇都是 7:1:2 → **条件一致**。同一份论文、只换口径，结论随之改变。）
5. 点任意一项的「🔍 查看双方证据」。
   （**预期**：侧栏按论文分别列出各自原文片段与页码。）

## 3b. 未找到 vs 未检查（核心卖点 2b）

1. 复现缺项里任意「未找到」项：理由应写明**正文所有页面都已处理**。
   （**预期**：这是"检索后未找到"。）
2. 若某篇论文有页面没被处理（正文过长被截断 / 页面抽不出文字），同一项会变成**「未检查」**，
   理由里点名具体页码。
   （**预期**：不会把没处理到的页面当作已经查过。）

## 4. 复现缺项与人工补充（核心卖点 3）

1. 切到「复现缺项检查」。
   （**预期**：DLinear 的学习率 / 优化器 / 随机种子 / 训练轮数 / 批大小 都是「未找到」——原文只说"用默认超参数、细节参考代码"。）
2. 在「学习率」点「✎ 补充 / 修正这一项」，填一个值后保存。
   （**预期**：该项状态变「人工补充」；卡片上出现「↳ 论文原文：未找到（该项为人工补充）」；
   另一篇论文自己的学习率仍显示为「已找到」且值不相同；顶部出现「含人工补充」提示。）
3. 总结条应显示：已找到 / 未找到 / 需要确认 / **人工补充** 四类计数。

## 5. 真实问答与引用（核心卖点 4）

1. 「论文问答」→ 点预设问题「这几篇论文的方法主要有什么区别？」。
   （**预期**：30 秒左右返回；提示「由模型阅读论文真实正文生成；引用已逐条回查原文」；若模型有引用对不上，会写明「已剔除 N 条」。）
2. 点回答里的任一引用。
   （**预期**：侧栏显示对应页的英文原句，标签为「PDF 原文」。）
3. 自由提问：「这篇论文的学习率、批大小、随机种子分别是什么？」
   （**预期**：如实回答哪些写了、哪些没写，不编造数值。）
4. 看回答里的**结论标签**（核心卖点 4b）：
   - 「原文支持」= 论文写了且引用能对上；
   - 「部分支持」= 原文只覆盖了一部分，鼠标停在旁边能看到理由；
   - 「系统事实」= 例如"本次只提供了 1 篇论文正文"，由程序状态证明，
     **不会因为论文里没写这句话而被撤回**，旁边会写出与程序状态是否一致；
   - 「规则推导」= 例如"采样间隔不同 → 不能直接比较"，下面会展开**输入字段 → 规则 → 结果**三段；
   - 「已撤回的结论」区块 = 提供的正文里找不到依据的**论文事实**类结论，已从回答里移除。
5. 单篇提问（只选 1 篇）后再问一个跨论文问题。
   （**预期**：关于"只有一篇"的说明标为**系统事实**并保留，不会被当成"论文里没写"而撤回。）
6. 找一条标「规则推导」的结论。
   （**预期**：展开「推导依据（规则 R-xx「规则名」）」+ 输入字段逐篇取值 + 规则 + 结果，
   并提示输入证据条数 —— 只有**程序真的执行过**的规则才有编号。）
7. 找一条模型自己提出、程序没有对应规则的比较类结论。
   （**预期**：标签为**「建议 / 待验证」**，明确写出"没有对应的、程序执行过的规则"。
   **不允许**因为模型自称是规则推导就显示成已验证的规则。）

## 5b. 生成验证计划（核心卖点 5）

入口：**实验检查页右上角「🧭 生成验证计划」**（左侧导航也有「验证计划」）。

1. 进入后先看表单：设备 / 时间 / 目标都有默认值，风险项默认勾好前 2 条 —— 不填也能生成。
2. 点「生成验证计划」。
   （**预期**：最多 3 个按优先级排列的实验卡片，每张都含：要确认的问题、为什么优先（写明对应哪条检查项与规则编号）、
   关键参数表、需要准备的数据/代码/环境、最小操作步骤、保持一致的条件、需要改变的变量、应记录的指标、
   什么结果支持/不支持假设、什么情况下停止。）
3. 看「关键参数」表的**来源**列。
   （**预期**：每项都标「论文给出的设置 / 工具建议的设置 / 待确认（论文没写清楚）」。）
4. 看「待确认项」区块。
   （**预期**：论文没写清楚的参数（学习率/批大小/轮数/种子、测试区间等）列在这里，**没有被编造数值**。）
5. 看「规模说明」。
   （**预期**：只说明设备与时间如何缩小规模，**不出现"几分钟能跑完""显存够用"这类承诺**；
   CPU + 1 小时会明确建议不训练模型。）
6. 勾几个步骤但**不要**填「实际结果」。
   （**预期**：状态最多到「待确认」，并出现「步骤勾完 ≠ 假设成立」的提示。）
7. 再填「实际结果」→ 状态变「已完成」。
   （**预期**：状态只表示"你记录完了"，界面不出现"验证成功/假设成立"。）
8. 点「导出 Markdown」。
   （**预期**：含参数来源、规则编号、步骤勾选状态、你的记录与那句提示。）
9. 点两个「示例场景」按钮。
   （**预期**：A：仅 CPU + 1 小时 → 优先级 1 是流程/口径核对且明确不训练；
   B：单张 GPU → 优先级 1 与公平比较的条件核对。实际输出见 `docs/PLAN-EXAMPLES.md`。）

## 6. 失败与边界

1. 上传一个 `.txt`。（**预期**：提示「格式不支持」，不加入列表。）
2. 上传一个改成 `.pdf` 后缀的文本文件。（**预期**：该条状态「解析失败」，原因写明"文件不是有效的 PDF"。）
3. 上传扫描件（图片版 PDF）。（**预期**：提示很可能是扫描件、需要先 OCR。）
4. 上传同一份文件两次。（**预期**：第二次提示「重复上传」。）
5. 刷新页面。
   （**预期**：论文列表、字段、证据、人工补充、问答历史全部恢复；
   点「用原文件重跑」可**无需重新选文件**直接重新解析 —— 这是本轮新增的能力。）
6. 在「运行设置」点「重置本地数据」。
   （**预期**：论文、字段、人工补充、问答历史与本地保存的原文件一起被清掉。）

## 7. 诚实性检查（容易被忽略但很重要）

1. 看到「未找到」时，界面是否说明**这不等同于论文有错误**，并给出补充入口？
2. 「未检查」是否与「未找到」分开显示，并点名页码？
3. 演示项目（示例项目）里是否处处标注「演示数据」？它与「我的论文库」是否完全隔离？
4. 关掉后端（停掉进程）后刷新 → 真实论文的问答是否**明确说明未连接模型**，而不是给固定答案？
5. 「运行设置」里的四个能力开关，是否只在真正跑通过之后才是绿色？
6. 数据集选择器：只被部分论文用到的数据集是否显示「x/y 篇包含」，且缺失方被标「信息不足」？
